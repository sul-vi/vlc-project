# Hierarchical M-CPAM Semantic VLC · v3

## 运行与结果

在项目根目录用 PowerShell 执行以下命令。首次使用时，先用 `python -m venv .venv` 创建虚拟环境，再用 `.\.venv\Scripts\python -m pip install -r requirements.txt` 安装依赖。运行脚本自动选择 CUDA、MPS 或 CPU。

默认的 CIFAR-10 归档由训练或评估脚本按需下载到 `data/`，并在读取前校验。

```powershell
# 使用已训练好的 v3 最佳权重
.\.venv\Scripts\python evaluate.py
# 从头训练到独立目录（会先在干净图像上训练分类器）
.\.venv\Scripts\python train.py --run v3_replica
.\.venv\Scripts\python evaluate.py --run v3_replica
.\.venv\Scripts\python -m unittest discover -s tests -v
```

默认权重目录为 `checkpoints/v3/`，结果目录为 `results/v3/`。旧的结果和权重保留在原处，v2 的源码快照在 `results/v2/第二版完整源码.md`。根目录的 `项目完整源码.md` 对应当前版本。

## 跨层消融

| 曲线 | 源编码与映射 | 物理模式 | 端到端分类输出 |
|---|---|---|---|
| JPEG + FEC 4:2:1 | 完整 JPEG、无损压缩、CRC、RM 纠错与物理交织 | 固定 8 阶 | 冻结分类器读取接收图像 |
| Unordered semantic 4:2:1 | 共享 CNN，各逻辑层在三种颜色上平衡打散 | 固定 8 阶 | 解交织后的逻辑核心位 → 任务头 |
| Ordered semantic 4:2:1 | 同一 CNN，逻辑核心位全部映射到红光 | 固定 8 阶 | 解调后的红路位 → 同一任务头 |
| Proposed 6:2:1 fixed | 相同有序映射，改变光强比例 | 固定 8 阶 | 解调后的红路位 → 同一任务头 |
| Proposed 6:2:1 adaptive | 相同有序映射和比例，按验证策略选模式 | 2、4 或 8 阶 | 解调后的红路位 → 同一任务头 |

前三个语义固定模式的对照分别隔离了映射顺序与光强比例。它们使用同一张图的同一组源比特、相同网络参数和相同的物理噪声实现。每张图独立生成颜色轮转次序，任一逻辑层的 1,024 位在物理 R、B、G 各占 341 或 342 位。接收端复用共享伪随机种子和帧顺序解交织，假设帧同步理想。程序为交织器和 AWGN 使用独立随机流。真实硬件需要实现双方的一致帧计数。

## 编解码器与训练

核心编码分支用干净分类器的前三个卷积块初始化，保留前两次池化得到 8×8 特征，再生成 16 个二值通道。另一卷积分支生成蓝绿各 16 个通道。共享编解码器端到端训练，红路任务头只读取接收端的**逻辑核心位**。重建头联合使用三层特征、三路活动标志和 SNR 条件，关闭的层置零。训练目标为
`MSE(重建图, 原图) + 0.5 × CrossEntropy(核心任务 logits, CIFAR-10 标签)`。两个头均无原图旁路。分类标签不进入发射比特流。

训练使用固定的 15,000 张 CIFAR-10 图像，训练留出集中固定选 1,024 张验证。每三个批次轮换三种映射/权重组合，两种均匀组固定 8 阶，非均匀组抽样嵌套模式。训练使用水平翻转、−5 到 25 dB 的连续噪声、10% 无噪全开样本和 30 轮余弦退火。按验证集联合损失最小保存共享 codec。本次复用 v2 同划分的干净分类器作为初始化来源与冻结评估器。语义任务头在 v3 训练。最终测试使用 10,000 张独立测试图，测试标签仅用于计算指标。

v3 自适应模式由验证集的双任务联合损失决定，目标与训练一致。模式图还显示 v2 的验证 PSNR 策略和测试单模式上界。任务准确率与重建质量随同一实际策略测量，两者各自的最优模式可能不同。阈值来自 5 dB 间隔的采样，插值精度需更密的验证测点支持。

## 符号预算与 JPEG

32×32 RGB 原图有 24,576 位。每个逻辑层为 16×8×8 = 1,024 位，固定 8 阶共 3,072 位，即 384 字节，是原始位数的 1/8。每个信息字发送原码与反码两个时隙，所有方案各占每图 2,048 个物理时隙。每个活动模式权重和为 1，逐图时间平均光强为 0.5。LED 采用中点对称 tanh 标定，两个时隙独立加噪。横轴为共同参考电 SNR，单时隙噪声方差为 `0.25 × 10^(-SNR_dB/10)`。

主对照在候选质量中选择同时满足两个预算的最高档。完整独立 JPEG 文件（含所有头部）须不超过 384 字节。随后对完整文件做无损 DEFLATE，所用公共字典由固定纯黑合成图生成，收发两端事先约定并使用相同字典。每帧的压缩结果和填充合计 116 字节，附加 4 字节 CRC32，共 120 字节，即 960 位。每 5 位分配一个 16 位的一阶 Reed–Muller 码字，192 个码字正好占 3,072 位，然后按固定置换交织发送。没有重传。每个码字最多 3 处硬判决错误能保证纠正。Walsh 变换实现硬判决下的最近码字译码。

每个像素、质量选择及图像相关表均来自收到的码流。预置字典由公开的固定算法生成，独立于训练/测试图像。接收端经纠错、CRC、限长无损解压后恢复完整 JPEG，按约定尺寸解码。CRC 或解码失败时输出中灰图，保留在图像指标和准确率分母。裸 JPEG 完整文件也受 384 字节约束，允许在自身预算内独立选质量，结果另存于 `jpeg_uncoded.csv`。两种实现具有相同的物理时隙和噪声，图像源质量及接收纠错能力可不同。

## 输出与指标

- `acc_vs_snr.png` 左图为端到端 Top-1，语义方法用直接核心任务头，JPEG 用重建图分类。右图让所有方案的重建图经过同一个冻结分类器，可直接与 v2 的重建分类指标对照。
- `psnr_vs_snr.png`、`ssim_vs_snr.png` 和 `visual_comparison.png` 比较全部五条曲线。重建拼图为相同测试图在 5 dB、15 dB 的输出。
- `ber_vs_snr.jpg` 的三个面板分别统计物理 R、B、G 误码。零误码通过空心倒三角显示在 0.5/N，关闭颜色没有比较位数。逻辑 R 的解交织后误码率见 CSV 的 `core_ber`。
- `mode_curves.jpg` 与 `mode_metrics.csv` 给出 6∶2∶1 三种固定模式和自适应模式的对比。
- `metrics.csv` 有五种方法 × 七个 SNR，共 35 行。`task_acc` 为直接任务头准确率，JPEG 留空。`recon_acc` 为统一冻结分类器的重建图准确率。`acc` 为端到端输出准确率。`physical_slots` 为该行所有测试图累计的物理时隙。
- `run.json` 保存全部训练/评估配置、选模轮次、逐模式验证值、策略阈值、无噪对照、干净原图分类上限、配对正确/错误计数和独立等概率位流的 BER 对照。配对计数中，两种方法的独占正确数之差除以图像数，即两者准确率差。
- 只评估原分辨率文件夹图像时可运行 `evaluate.py --dataset folder --data-dir D:\images\kodak --image-size 0 --batch-size 1 --output-dir results/kodak_v3`，测试图放在 `test/`。无 CIFAR-10 标签时仅输出重建和通信指标。


## 本次 CIFAR-10 仿真结果

训练图像 15,000 张，训练 30 轮，验证集选择第 29 轮。测试集为独立的 10,000 张图像。下表为端到端 Top-1，JPEG 使用重建图分类器，四条语义曲线使用逻辑核心位的任务头。

| SNR | JPEG + FEC | 无序 4∶2∶1 | 有序 4∶2∶1 | 固定 6∶2∶1 | 自适应 6∶2∶1 | 自适应阶数 |
|---:|---:|---:|---:|---:|---:|---:|
| -5 dB | 10.00% | 49.93% | 66.49% | 69.35% | 72.66% | 2 |
| 0 dB | 10.00% | 60.79% | 72.40% | 73.57% | 74.52% | 4 |
| 5 dB | 10.00% | 68.41% | 74.14% | 75.30% | 75.30% | 8 |
| 10 dB | 10.00% | 72.84% | 75.01% | 75.67% | 75.67% | 8 |
| 15 dB | 10.00% | 74.88% | 75.41% | 75.47% | 75.47% | 8 |
| 20 dB | 46.99% | 75.40% | 75.52% | 75.47% | 75.47% | 8 |
| 25 dB | 47.99% | 75.45% | 75.46% | 75.47% | 75.47% | 8 |

−5 dB 的三步消融分别贡献 +16.56、+2.86、+3.31 个百分点。第一步只改变交织，第二步只改变权重，第三步切换到仅红光。对应的四条语义曲线 PSNR 依次为 18.09、16.63、15.68 和 14.00 dB。该结果说明在此工况下优先保护分类会损失图像保真度。无噪全开时，三种固定语义方案的直接任务 Top-1 均为 75.47%，同一冻结分类器的重建图 Top-1 均为 38.21%，原图参照为 76.17%。与 v2 对照时须注意码率和任务读出都已改变。

七个测试点上，完整 JPEG 的发送端预算失败均为零。主对照在 15、20 和 25 dB 分别成功解码 1、9,738、10,000 张图像。裸 JPEG 在 20 和 25 dB 分别成功解码 0 和 4,650 张。纠错占用帧预算后，保护版无噪 PSNR 为 21.92 dB，裸 JPEG 为 23.41 dB，体现源质量与误码保护的取舍。
